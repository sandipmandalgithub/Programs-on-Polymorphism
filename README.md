# Java Polymorphism Programs

This repository contains Java programs demonstrating **Polymorphism** in Object-Oriented Programming (OOP).

These programs were created to practice and understand how the same method or reference can behave differently in different situations.

## 📚 Concepts Covered

### Compile-Time Polymorphism

* Method Overloading
* Different parameter lists
* Method selection at compile time

### Runtime Polymorphism

* Method Overriding
* Inheritance
* Parent class reference and child class object
* Dynamic Method Dispatch

## 🛠️ Technologies Used

* **Programming Language:** Java
* **IDE:** Eclipse IDE

## 🚀 How to Run

1. Clone or download this repository.
2. Open the Java source files in Eclipse IDE or another Java IDE.
3. Open the desired Java class.
4. Run the program as a Java Application.

## 🎯 Purpose

This repository was created for Java programming practice and to strengthen my understanding of **Polymorphism, Method Overloading, Method Overriding, and Inheritance** in Java.
